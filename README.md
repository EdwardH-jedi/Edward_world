# Edward's World

A deliberately unstyled technical foundation for an interactive personal developer portfolio. It includes a title and intro state machine, a horizontally navigable world, typed proximity interactions, and an accessible recruiter-facing index.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

See `docs/ARCHITECTURE.md` for the state, data, input, accessibility, and visual-extension boundaries.
